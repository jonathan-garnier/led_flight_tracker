# Setup guide images

Drop the screenshots/photos referenced by the main [README](../../README.md)
here, using these exact filenames so the links resolve:

| Filename | What it should show |
| -------- | ------------------- |
| `hero.jpg` | The assembled tracker displaying a real flight (banner image). |
| `opensky-signup.png` | OpenSky Network registration / sign-up page. |
| `opensky-credentials.png` | OpenSky **API Clients** section showing where the Client ID / Secret appear (blur the real values). |
| `device-setup-mode.jpg` | The LED panel showing the setup / config-mode message. |
| `setup-form.png` | The device's setup web form (served at `http://192.168.4.1`). |
| `device-settings-address.jpg` | The LED panel scrolling "Settings at: flighttracker.local". |
| `settings-page.png` | The full settings page (`flighttracker.local/settings`). |
| `settings-tracking-area.png` | The map / bounding-box selector on the settings page. |
| `settings-reset.png` | The **Reset Device** button at the bottom of the settings page. |

Tips:
- Use PNG for screenshots, JPG for photos.
- Crop tightly and **blur any real WiFi passwords or OpenSky secrets**.
